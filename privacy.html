BrainAI privacy policy

Last updated: 22 October 2026

Who uses BrainAI

BrainAI is a personal tool used only by its owner. It is not offered to the public, and only the owner's own Google account is connected to it.

What data it accesses

With the owner's permission, BrainAI uses read-only access to the owner's Gmail, Google Calendar, Google Drive and Google Contacts:

  • gmail.readonly
  • calendar.readonly
  • drive.readonly
  • contacts.readonly

It never sends, changes or deletes anything in the Google account.

How data is stored and used

Data is downloaded to, and stored only on, the owner's own computer, so that the owner can search it. It is not uploaded to any server run by BrainAI. It is not sold or shared, and it is not used for advertising. When the owner asks an AI assistant a question, only the short excerpts relevant to that question are sent to the assistant.

Google API Services User Data Policy

BrainAI's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access and data

Access can be removed at any time at myaccount.google.com/permissions. Deleting BrainAI's local data folder removes all stored data.
